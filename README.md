## Présentation

`Logiciels Utiles by Mathys M` regroupe une sélection de logiciels que je recommande pour Windows.

Chaque logiciel est classé dans une catégorie afin de retrouver facilement les outils dont vous avez besoin.

## Comment ça fonctionne ?

Le dossier contient les logiciels, scripts et ressources nécessaires à leur utilisation.

Les scripts `.bat` permettent notamment d'automatiser certaines installations ou téléchargements.

Le dépôt GitHub permet également de consulter librement les fichiers et les scripts utilisés par le projet.
